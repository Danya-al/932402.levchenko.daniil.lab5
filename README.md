## Описание

Скрипт добавляет на страницу интерактивный список рецептов с сохранением состояния между перезагрузками.

## Поиск элементов

- `getElementById` — кнопки управления и контейнер рецептов
- `querySelector` — проверка наличия элементов интерфейса
- `querySelectorAll` — подсчёт отрисованных карточек

## Манипуляции с DOM

- `createElement` и `append` — построение карточки рецепта со списком ингредиентов
- `textContent` — установка текста заголовков и пунктов списка
- `classList.toggle` и `classList.contains` — переключение классов `hidden` и `dark`

## Функции интерфейса

- **Добавить рецепт** — два `prompt` (название и ингредиенты через запятую), строка разбивается методом `split`
- **Удалить последний** — удаление последнего элемента массива через `pop`
- **Скрыть рецепты** — переключение класса `hidden`
- **Тёмная тема** — класс `dark` на `body`, цвета переопределяются через CSS-переменные

## Обработка ошибок

- Проверка существования элементов перед работой с ними, сообщение через `console.error`
- `try / catch` при разборе данных из localStorage на случай повреждённой записи
- Проверка пустого списка перед удалением

## localStorage

Рецепты хранятся в виде JSON-строки (`JSON.stringify` при записи, `JSON.parse` при чтении), тема — отдельным ключом. При загрузке страницы состояние восстанавливается: применяется сохранённая тема и отрисовываются сохранённые рецепты.
